# Security policy

## Supported versions

Only the latest release is supported. Security fixes ship in a new release;
older releases are not updated.

## Reporting a vulnerability

Please report a suspected vulnerability privately, through this repository's
**Security** tab: choose **Report a vulnerability**.

Do not describe it in a public issue, pull request or discussion.

A useful report includes:

- the release you used
- the steps that reproduce the problem
- what someone could do by exploiting it

There is no fixed timeline for a reply, a fix or a disclosure.
