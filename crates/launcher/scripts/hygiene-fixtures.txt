# Samples for the commit checker's and the hygiene scan's self-tests
# (commit-check.selftest.ts, hygiene-scan.selftest.ts). Every name, address,
# path and id in this file is invented.
#
# A block is a line "@@ <kind> <name>", then "key: value" lines, then a line
# "text:"; the text runs from the next line to the next line that starts with
# "@@ ". "expect: <rule>" names a rule the sample must hit, and
# "expect: <rule> -- <words>" also names words its hit line holds; a block
# without an expect line must pass. "needle: <text>" is planted text that no
# output may repeat. In a text, \u{<hex>} stands for that code point, so this
# file stays ASCII.
#
# Commit keys: class (dependabot, github-merge, maintainer or other), author
# and committer (addresses; the committer defaults to the author, the author
# to the maintainer's plain noreply address), parents (2 makes a merge whose
# second parent is the range's base), adds (paths the commit adds), renames
# (<old> -> <new>), range (the group the commit is built into, in file order),
# branch and branch-expect (the group's branch name and what it must hit).
# The synthetic repository owner is sample-owner.
#
# Pull request keys: field (title, body or branch: the one the text fills; the
# others keep clean values) and login (the author's login, by default
# sample-contributor). A trap's text is clean and is used as a commit message,
# a pull request body and a file.
#
# File keys: path (where the text is written in the scratch repository), exec
# (yes: tracked with mode 100755; every *.sh is executable on disk whatever
# its tracked mode) and suppressed (the hits an exempt path must report as
# suppressed).
