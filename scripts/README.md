# scripts

| Script | What it does | Run |
|---|---|---|
| `build.sh` | Release build (vite build + `cargo xwin build --locked`) into `release/` (cleared first): the exe cargo built, read from cargo's target directory, and `config.example.toml`. Sets `RUSTFLAGS` to remap the home directory in compiled-in paths and to turn on Control Flow Guard and CET compatibility (only Rust code compiled with the flag is instrumented), and repeats cargo-xwin's sysroot includes in `TARGET_CFLAGS_<target>` with the same remap for the C dependencies; clears the three wrapper/flag variables; exports the SDK and CRT pins from `scripts/ci-tools.env` and fails if the SDK directory for that pin is absent after the build. | `./scripts/build.sh` |
| `binary-audit.sh` | `binary-audit.sh audit [--public-runner] [--expected-version <v>] <dir\|zip\|file>...` counts path and key shapes (ASCII and UTF-16LE) and checks the exe's PE flags; `self-test` proves every shape is caught and no known false positive is; `shapes` prints the shape list. Identity strings come only from `CI_CHECK_IDENTITY`, never printed. | `./scripts/binary-audit.sh self-test` |
| `ci-check.sh` | The step table and its runner: each check is one `row`; a plain run executes every row this machine can run and ends by naming each row it did not run and why; `--job <tag>` runs one CI job's rows; `--list` prints the table. Missing or different tool versions fail their rows. Run it after `cargo fmt` too. | `./scripts/ci-check.sh` |
